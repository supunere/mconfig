# mconfig

条件に応じた設定を、プリセットと割り当てで管理するWindowsアプリです。
用途・筐体タイプ・製品グレードなどの組み合わせに対し、カテゴリごとの設定を割り当てます。

## 使い方

Windows 11 x64で配布ZIPをフォルダーに展開し、Mconfig.App.exeを起動してください。
「組み合わせと値」で条件とプリセットの値を確認・編集し、「割り当て」で上から順に適用する条件を管理します。
「保存と履歴」で変更を保存し、「出力」で設定データのテスト版・リリース版ZIPを作成できます。
アプリ配布ZIPと、アプリから出力する設定データZIPは別のものです。

初回起動では、既存データを選ぶか同梱サンプルからワークスペースを作成するかを選択します。
既定の保存先は `%LOCALAPPDATA%\mconfig\workspace` です。既存のデータがある場合はそのデータを読みます。
確認用サンプルを独立して試す場合は、起動引数 `--workspace "C:\mconfig-review\workspace"` のように、空の確認用フォルダーの絶対パスを指定してください。
既存の作業データは削除せず、別の確認用フォルダーを指定することを推奨します。

## 同梱PC構成サンプル

用途はオフィス・ゲーミング・コンテンツ制作、筐体タイプはタワー・省スペース・ノート、製品グレードはエントリー・スタンダード・ハイエンドの27通りです。
CPU・メモリ・ストレージの14プリセットと16割り当てを含みます。条件のanyはすべての値に一致し、上の行が優先されます。
ストレージのシングルドライブ構成はデータ用ドライブのグループを未使用（JSONのnull）にしています。
サンプルは設定管理の例で、PCのハードウェアを操作する機能はありません。
定義と画面の表示名は日本語・英語に対応します。条件値とプリセット名は共通の日本語文字列です。

| 日本語の条件値 | English meaning |
| --- | --- |
| オフィス / ゲーミング / コンテンツ制作 | Office / Gaming / Content creation |
| タワー / 省スペース / ノート | Tower / Compact / Notebook |
| エントリー / スタンダード / ハイエンド | Entry / Standard / High-end |

## ビルド

.NET 10 SDKを使用します。

```powershell
dotnet build src/mconfig.slnx -c Release
dotnet publish src/Mconfig.App/Mconfig.App.csproj -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```
