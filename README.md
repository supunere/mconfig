# mconfig

条件に応じた設定を、プリセットと割り当てで管理するWindowsアプリです。
用途・筐体タイプ・製品グレードなどの組み合わせに対し、カテゴリごとの設定を割り当てます。

## 使い方

Windows 11 x64で配布ZIPをフォルダーに展開し、Mconfig.App.exeを起動してください。
「組み合わせと値」で条件とプリセットの値を確認・編集し、「割り当て」で上から順に適用する条件を管理します。
設定が完成したら「発行」で変更内容と検証結果を確認し、発行理由を入力して配布用ZIPを作成します。成功すると自動で履歴に残り、「履歴」で過去のバージョンを確認・復元できます。
通常の「保存」（Ctrl+S）は作業途中の編集をファイルに保存します。発行先はワークスペースの `exports` フォルダーです。エラーまたは警告がある場合は発行できません。失敗した場合は原因を解消して「発行する」を押し直してください。履歴への記録やZIP作成の再試行はアプリが管理します。
アプリ配布ZIPと、アプリから出力する設定データZIPは別のものです。

初回起動では、既存データを選ぶか同梱サンプルからワークスペースを作成するかを選択します。
既定の保存先は `%LOCALAPPDATA%\mconfig\workspace` です。既存のデータがある場合はそのデータを読みます。
確認用サンプルを独立して試す場合は、起動引数 `--workspace "C:\mconfig-review\workspace"` のように、空の確認用フォルダーの絶対パスを指定してください。
既存の作業データは削除せず、別の確認用フォルダーを指定することを推奨します。

## 同梱PC構成サンプル

用途はオフィス・ゲーミング・コンテンツ制作、筐体タイプはタワー・省スペース・ノート、製品グレードはエントリー・スタンダード・ハイエンドの27通りです。
CPU・メモリ・ストレージの14プリセットと16割り当てを含みます。条件のanyはすべての値に一致し、上の行が優先されます。
ストレージのシングルドライブ構成はデータ用ドライブのグループを未使用（JSONのnull）にしています。
サンプルは設定管理の例で、PCのハードウェアを操作する機能はありません。
定義と画面の表示名は日本語・英語に対応します。条件値とプリセット名は共通の日本語文字列です。

| 日本語の条件値 | English meaning |
| --- | --- |
| オフィス / ゲーミング / コンテンツ制作 | Office / Gaming / Content creation |
| タワー / 省スペース / ノート | Tower / Compact / Notebook |
| エントリー / スタンダード / ハイエンド | Entry / Standard / High-end |

## ビルド

.NET 10 SDKを使用します。

```powershell
dotnet build src/mconfig.slnx -c Release
dotnet publish src/Mconfig.App/Mconfig.App.csproj -c Release -r win-x64 --self-contained true -p:Version=0.1.0 -p:RuntimeFrameworkVersion=10.0.12 -o artifacts/win-x64
```

配布ZIPの作成と同梱文書は[RELEASE.md](RELEASE.md)を参照してください。ランタイム版を変える場合は、依存ライセンス文書も確認してください。

## テスト

```powershell
dotnet test tests/Mconfig.Presentation.Tests/Mconfig.Presentation.Tests.csproj -c Release
```

検証結果の鮮度、編集・復帰・非同期処理に加え、発行成功時だけ履歴へ追加すること、各処理段階の失敗・再起動後に再試行してもZIPと履歴が重複しないことを確認します。
UIでの確認範囲と結果は[動作確認記録](docs/ui-review-2026-10-15.md)を参照してください。
画面は標準WinFormsを基本とします。見た目と配置のルールは[画面の基本方針](docs/ui-guidelines.md)を参照してください。

## バックアップと復元

アプリを終了してから、ワークスペースのフォルダー全体を別の媒体へコピーしてください。設定データだけでなく、履歴を含む隠しフォルダーも保存します。同じディスク上の履歴だけでは、ディスク故障への備えになりません。

復元するときは、バックアップ一式を別の書き込み可能なフォルダーへコピーし、`--workspace` でその絶対パスを指定して起動します。元のワークスペースは上書きせず、設定値と履歴が読み込めることを確認してください。
出力した設定データZIPはワークスペース全体のバックアップとは別に保管してください。
