# 標準WinFormsの採用と確認

ブランチ: `codex/native-winforms-trial`

実画面比較と位置ずれ修正を経て、ユーザーの選択により標準WinForms版をベースに採用した。独自のフラット描画を外し、Windows標準のボタン、表の枠、選択色、ツールバー、システムフォントを使う。見出し帯はシステムのControl色、見出しは通常のLabelとし、全体の行高・余白を小さくした。値の差分・未入力の状態色、選択中プリセットの見出し色と太字は意味を持つため残した。今後の方針は [画面の基本方針](ui-guidelines.md) を参照。

共通の外観を変更したため他画面のボタン・表・リストにも標準スタイルが適用される。採用時には「組み合わせと値」「割り当て」「保存と履歴」「出力」の初期表示と画面切替を実画面で確認した。機能・Presenter・リソースは変更していない。

採用時に、割り当ての背景・表内コンボボックス、履歴の理由入力欄、出力欄のカード風の装飾、ステータスバーの通常背景も標準の見た目に揃えた。

## 組み合わせ表の2段ヘッダー

別置きしていた「組み合わせの条件」「割り当て結果」のPanelとLabel、条件と結果の間を表の下端まで引く追加の線を削除した。上段は列グループ、下段は各列名として、DataGridViewのヘッダー領域内に収めた。本文の列境界は通常の表の罫線のみ。

WinFormsには結合ヘッダーがないため、GroupedHeaderGridで上段だけをWindowsテーマに合わせて描き、下段は標準の列ヘッダー描画を使う。列幅変更・横スクロールは表の列座標から上段を描き直す。上段はグループの状態を表す色を付けず、条件列が0本なら結果側だけを表示する。列名はHeaderTextに保持し、ツールチップにもグループと列名を入れる。

Releaseビルドは警告・エラー0。回帰テスト10件、既存の絞り込み配置検査も成功。実WinFormsの描画検査で、通常の2グループ・横スクロール・結果列だけ・英語・16ptの画像を出力して確認した。Computer Useでも2段が表内に収まることと選択中見出しの表示を確認した。高コントラスト・各DPIでの実機網羅確認は含まない。

最新の画面画像は `artifacts/ui-native-winforms/grouped-header.png`。

上段の罫線も下段に揃えるため、上段の直接テーマ描画を標準ヘッダーセルの描画に変更した。DataGridViewが各セルに調整した境界設定を使い、上段だけ二重線になるのを防いでいる。段の境目は下段の上辺を共有して1本にした。確認環境の描画画像では、上下のグループ境界が同じ座標・色で1px幅、段の境目も1pxであることを確認した。Releaseビルドは警告・エラー0、既存の配置・ヘッダー描画検査も成功。

罫線修正版の実画面画像は `artifacts/ui-native-winforms/header-lines.png`。
