# 画面の基本方針

2026-10-15の実画面比較で、標準WinFormsをベースにする方針を採用した。

- Windowsのシステムフォント・システム色と標準コントロールを使う。ボタン、入力欄、表、ツールバー、一覧の標準描画を優先する。
- 領域を分けるためのカード、影、大きな見出し帯、独自の選択枠は追加しない。Dock／Anchor、TableLayoutPanel、FlowLayoutPanelと通常の余白で配置する。
- 余白は4px／8pxを基本とし、見出し、入力欄、操作の左端と縦中央を揃える。表を読む領域を優先する。
- 見出しは本文と同じサイズのLabelを基本とする。「組み合わせと値」の領域見出しは太字と細い緑の縦線で揃える。
- 色は選択・差分・未入力・警告など意味のある状態に使い、文言も併記する。領域の区切りに選択色を流用しない。高コントラストではシステム色を使う。
- 高さはPreferredSize／PreferredHeightに追従させる。ComboBoxの必要高と下余白を確保し、固定高や負の余白で収めない。
- 表の列幅は標準ヘッダーの内側の余白と太字を考慮する。値ペインが非表示でも項目名を測り、初回表示で文字が欠けないようにする。
- 組み合わせ表は標準DataGridViewの1段ヘッダーを使う。グループ用の追加ヘッダーや、本文を貫く区切り線を描かない。
- 新しい機能や装飾は見た目の調整と一緒に追加しない。通常幅・最小幅、開閉、条件選択、文字拡大、長い表示名を確認する。

「組み合わせと値」は、値の表の列順を固定し、選択中プリセットの見出しを強調する。差分の基準は選択中プリセットとし、初期表示は全プリセット。「表示するプリセット…」で表示対象を選ぶ。この表示ルールを見た目の変更で変えない。

この画面の主な役割は値の確認と修正とする。上の表と重複する「選んだ組み合わせ」の説明は表示しない。プリセットの追加・複製・名前変更・削除は「割り当て」画面の下側の「プリセット管理」領域に集約し、この画面には置かない。表示対象の選択は通常の操作として残し、共有プリセットを編集するときの影響確認も維持する。

採用までの比較と確認は [標準WinFormsの確認記録](ui-native-winforms-trial.md) に記録する。

絞り込みはラベル付きの標準ComboBoxを並べ、初期状態では条件を表示する。バッジ表示は使わない。「条件を隠す」でのみ折りたたみ、条件の全文と「条件を表示」で状態と復帰方法を示す。折りたたんでも条件は維持する。

折りたたみ中は指定した条件を通常のLabelですべて表示する。長い場合は折り返し、省略記号や「ほかN条件」は使わない。件数は「全N件中M件」と表記する。凡例は操作ボタンと区別し、枠を付けない。編集案内は編集可能なセルにだけ表示する。

「組み合わせと値」は絞り込み領域全体を薄いグレー、組み合わせ・値領域を白背景にする。各見出し左に幅3px・文字高程度の緑線を置く。標準PanelとLabelで構成し、独自描画や上下の装飾罫線は追加しない。高コントラストではシステム色を使う。

開閉ボタンは各見出し行の右端に配置する。値の表を閉じてもカテゴリ名と開閉ボタンは残し、表・操作欄・凡例だけ折りたたむ。再表示で元の分割比率を復元する。

値の表の右上に「選択中のプリセットとの差分」の説明だけを表示する。「凡例：」と、セル自体に書かれている未入力・使用しない・未保存*の重複説明は置かない。

「割り当て」は左に共通のカテゴリ一覧、右上に「割り当てルール」、右下に「プリセット管理」を配置し、標準の分割バーで高さを調整する。各領域は白背景とし、間にはグレーの隙間を残す。プリセット管理は選択カテゴリの全プリセットを一覧で表示・編集し、組み合わせ由来の選択見出し・差分基準・表示対象選択・ペイン開閉は持ち込まない。編集処理を共通化しても、画面のカテゴリと選択状態は独立させる。カテゴリ・画面切り替え時は入力を確定し、共有編集確認と読み取り専用の制限を維持する。

保存の表示名は「保存」（現在の編集をファイルに保存、Ctrl+S）と「履歴に残す」（変更理由と復元可能な版を記録）に統一する。「一時保存」「履歴に保存」は画面に使わない。状態は「保存済み」「履歴に未記録／履歴に記録済み」とする。内部のSaveDraft／Commit APIや保存方式は表示名の変更で改変しない。
